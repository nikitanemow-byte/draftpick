# Инструкция по установке на хостинг Beget

Вы можете запустить сайт на Beget **двумя простыми способами**:

---

## Вариант 1: Самый простой (Статический HTML/CSS/JS — работает на ЛЮБОМ тарифе Beget за 1 минуту)

Файл `index.html` в этой папке полностью автономен: он содержит весь адаптивный дизайн в стиле Dota 2 HUD, чистые CSS-стили (без внешних зависимостей) и встроенный движок подбора контрпиков с репликами Пуджа.

### Шаги для Beget:
1. Зайдите в панель управления Beget: `cp.beget.com`.
2. Перейдите в раздел **«Файловый менеджер»** (или подключитесь по SFTP / FTP).
3. Откройте папку вашего сайта:
   ```
   /ваш_домен/public_html/
   ```
4. Загрузите файл `index.html` прямо в папку `public_html`.
5. Откройте ваш домен в браузере — сайт мгновенно работает без настроек сервера!

---

## Вариант 2: Python Backend (FastAPI / WSGI) на Beget

Если вам требуется отдельный Python-сервер с JSON API:

1. В панели управления Beget перейдите в раздел **«Сайты»** -> выберите сайт -> вкладка **«Python / WSGI»**.
2. Выберите версию Python: **Python 3.10+**.
3. Загрузите файл `counterpicks.py` в корень сайта.
4. Установите зависимости через встроенный SSH-терминал Beget:
   ```bash
   pip install fastapi uvicorn
   ```
5. Запуск сервера:
   ```bash
   uvicorn counterpicks:app --host 0.0.0.0 --port 8000
   ```
6. API будет доступно по адресу:
   ```
   GET /api/counterpicks?heroes=Phantom+Assassin,Sniper
   ```

- Дизайн в мрачно-кинематографичном стиле Dota 2 (темный градиент, акцентные красный Radiant и зеленый Dire, золотистые рамки HUD).
